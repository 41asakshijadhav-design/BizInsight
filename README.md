# BizInsight – Business Analytics Dashboard

## Project Overview
BizInsight is a business analytics dashboard developed using HTML, CSS, and JavaScript. It presents business information through charts, tables, and summary cards.

## Live Website
[Visit BizInsight](https://41asakshijadhav-design.github.io/BizInsight/)

## Features
- Dashboard with important business statistics
- Monthly Revenue Analytics
- Sales by Category
- Customer Growth and Segmentation
- Product Analytics
- Business Insights and Recommendations
- Regional Sales Analytics
- Recent Transactions
- Interactive charts
- CSV Report Download
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Chart.js

## Project Screenshot
![BizInsight Dashboard](screenshots/dashboard.png)

## Project Objective
To demonstrate how business data can be presented visually and clearly using web technologies.

## How to Run
1. Download the project.
2. Open the BizInsight folder in VS Code.
3. Open `index.html` in a browser.

**Note:** This project uses sample data for demonstration purposes.
